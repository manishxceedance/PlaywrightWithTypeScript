Numbers

Practice arithmetic, rounding, conversion, formatting, and useful Math helpers.

How to Use This Page

Read the explanation first. Try the sample yourself, then compare the type choices and comments. Change one value at a time and predict the result before running it.

Examples

Method NameExplanationConcrete Sample
Arithmetic operatorsAdd, subtract, multiply, divide, find a remainder, or calculate powers.
const total = 20 + 6;
      const remainder = 20 % 6;
      const squared = 6 ** 2;
      console.log(total, remainder, squared); // 26 2 36
Comparison operatorsCompare values and receive a boolean result.
const retries = 2;
const status = "passed";
const canRun = retries < 3;
const isEqual = status === "passed";
console.log(canRun, isEqual); // true true
Math.round()Rounds to the nearest integer.
const whole = Math.round(12.6); // 13
Math.floor() / Math.ceil()Rounds down or up to the nearest integer.
const lower = Math.floor(12.9); // 12\nconst higher = Math.ceil(12.1); // 13
Math.trunc()Removes the decimal portion without rounding.
const seconds = Math.trunc(12.9); // 12
toFixed()Formats a number with a fixed number of decimal places and returns a string.
const price = 12.5.toFixed(2); // "12.50"
toPrecision()Formats to a number of significant digits and returns a string.
const display = (1234.56).toPrecision(4); // "1235"
Number()Converts an entire valid numeric string into a number.
const port = Number("3000");
parseInt() / parseFloat()Parses an integer or decimal from the beginning of a string.
const count = parseInt("12 tests", 10);
const rate = parseFloat("99.5%");
console.log(count, rate); // 12 99.5
Number.isNaN()Checks whether a value is the special NaN value.
const invalid = Number.isNaN(Number("unknown")); // true
Number.isInteger()Checks whether a number has no fractional part.
const complete = Number.isInteger(42); // true
toString(radix)Converts a number to text in binary, octal, or hexadecimal.
const hex = (255).toString(16); // "ff"
Math.max() / Math.min()Finds the largest or smallest value in a list.
const fastest = Math.min(320, 180, 250); // 180
Math.abs()Returns the positive magnitude of a number.
const actual = 87;
const expected = 100;
const difference = Math.abs(actual - expected);
console.log(difference); // 13
Math.sqrt() / Math.cbrt()Calculates square and cube roots.
const root = Math.sqrt(64); // 8
Math.random()Returns a number from zero (inclusive) to one (exclusive).
const sample = Math.random();
