Typed API calls

Describe response data so consumers know what an HTTP call returns.

How to Use This Page

Read the explanation first. Try the sample yourself, then compare the type choices and comments. Change one value at a time and predict the result before running it.

Typed API callsDescribe response data so consumers know what an HTTP call returns.
interface user{
    id:number;
    name:string;
    email:string;
    phone:string;
    address:string;
    age:number;
}

async function getUserDetails(): Promise<user[]> {
    const response = await fetch("https://jsonplaceholder.typicode.com/users");
    let users: user[] = [];
    let data: user  = await response.json();
    return [
        {
            id: data.id,
            name: data.name,
            email: data.email,
            phone: data.phone,
            address: data.address,
            age: Math.floor(Math.random() * 50) + 20 // Random age for demonstration
        }
    ];
}
async function main() {
    console.log(await getUserDetails());
}
main();
