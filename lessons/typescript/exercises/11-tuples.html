Tuples

Use a fixed-position collection when each position has a different meaning.

How to Use This Page

Read the explanation first. Try the sample yourself, then compare the type choices and comments. Change one value at a time and predict the result before running it.

Examples

Method NameExplanationConcrete Sample
TuplesUse a fixed-position collection when each position has a different meaning.
// A tuple is a fixed-length array where each position has a known type.

// 1. Basic tuple: the first item must be a string and the second must be a number.
const user: [string, number] = ['Manish', 30];
console.log('basic tuple:', user);
console.log('name:', user[0]);
console.log('age:', user[1]);

// 2. Labeled tuple: labels improve readability but do not change the types.
const employee: [name: string, age: number, department: string] = [
	'Anita',
	28,
	'QA',
];
console.log('labeled tuple:', employee);

// 3. Optional tuple element: the optional item can be omitted or undefined.
const addressWithCountry: [street: string, city: string, country?: string] = [
	'MG Road',
	'Pune',
];
console.log('optional tuple:', addressWithCountry);

// 4. Rest tuple: the first item is fixed, followed by zero or more numbers.
const scores: [student: string, ...scores: number[]] = ['Ravi', 80, 90, 95];
console.log('rest tuple:', scores);

// 5. Readonly tuple: items cannot be changed after creation.
const coordinates: readonly [number, number] = [18.52, 73.85];
console.log('readonly tuple:', coordinates);
// coordinates[0] = 20; // Error: a readonly tuple cannot be modified

// 6. Union of tuples: the value must match one of the listed tuple shapes.
const result: ['success', number] | ['error', string] = ['success', 200];
console.log('union tuple:', result);

// 7. Nested tuple: a tuple can contain another tuple as one of its items.
const userWithLocation: [string, [number, number]] = [
	'Neha',
	[18.52, 73.85],
];
console.log('nested tuple:', userWithLocation);

// 8. Function parameter tuple: describes the arguments accepted by a function.
type LogArguments = [message: string, repeatCount?: number];
function logMessage(...args: LogArguments): void {
	const [message, repeatCount = 1] = args;
	console.log(message.repeat(repeatCount));
}
logMessage('Hello', 2);

// 9. Function return tuple: documents multiple values returned in a fixed order.
function getUser(): [name: string, age: number] {
	return ['Priya', 25];
}
const [userName, userAge] = getUser();
console.log('returned tuple:', userName, userAge);

// 10. Tuple type created with a const assertion: values and positions are readonly literals.
const httpStatus = [200, 'OK'] as const;
console.log('const tuple:', httpStatus);
console.log(httpStatus[0]);
console.log(httpStatus[1]);
