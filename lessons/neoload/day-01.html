Week 1, Day 1: NeoLoad 2026.02 and Performance Testing Basics

BeginnerInstall the tool, launch the sample application, and record your first user path.

What you will complete today

  1. Install and verify NeoLoad 2026.02 on Windows.
  2. Open the published Login - HRMS Practice App training endpoint.
  3. Understand response time, throughput, users, and errors.
  4. Record and replay a basic sample journey in NeoLoad.

Time: 60-90 minutes. Use a non-production environment only.

1. Prepare your computer

Before installing NeoLoad, make sure you have Windows permission to install software, a supported Java/runtime configuration according to the NeoLoad 2026.02 release notes, an approved NeoLoad account or license, and this training repository on your computer.

Download the NeoLoad 2026.02 Windows installer from your organization's approved Tricentis/NeoLoad download portal. Do not use an installer from an untrusted mirror.

2. Install NeoLoad 2026.02

  1. Close other NeoLoad instances and run the downloaded installer as a normal Windows application.
  2. Accept the license terms, keep the default installation location unless your team requires another location, and finish the installation.
  3. Open NeoLoad from the Start menu.
  4. Sign in or activate the license using your organization's approved method.
  5. Open Help > About and confirm that the installed version is 2026.02.

Evidence: save a screenshot of the About/version dialog without exposing license keys, account names, or tokens.

3. Open the sample application

Use the published HRMS Practice App training endpoint below. It is an HTTP URL suitable for NeoLoad recording and avoids recording a local file:// path.

Open Login - HRMS Practice App

Direct URL for NeoLoad recording:

https://manishxceedance.github.io/PlaywrightWithTypeScript/lessons/practice-app/hrms/login.html

Check: the page title is Login - HRMS Practice App and the login form and Sign In control are visible.

4. Learn the four measurements

  • Response time: how long a request or business transaction takes.
  • Throughput: how much work completes per unit of time.
  • Concurrent users: how many virtual users are active at once.
  • Error rate: the proportion of failed requests or business checks.

For this first lab, the goal is not to create heavy load. The goal is to prove that NeoLoad can model and replay one valid journey.

5. Record your first NeoLoad user path

  1. In NeoLoad 2026.02, create a new project named neoload-training.
  2. Start a web recording and use the URL from step 3.
  3. In the HRMS Practice App, enter the approved local training account values provided by your instructor or environment owner.
  4. Click Sign In and wait for the HRMS dashboard to open.
  5. Stop recording and save the user path as UP_HRMS_Login.
  6. Replay the path with one virtual user. Confirm that the page loads and the recorded requests complete without errors.

Do not increase virtual users today. This is a functional smoke check before performance workload design.

Day 1 completion checklist

  • NeoLoad About dialog shows version 2026.02.
  • Login - HRMS Practice App opens from the published HTTPS endpoint.
  • The UP_HRMS_Login user path is saved.
  • A one-user replay completes successfully.
  • You saved the version screenshot and replay result.

Common problems

  • NeoLoad will not start: check the 2026.02 release prerequisites and your organization's installation policy.
  • License cannot be activated: confirm that you are using the approved account, proxy, or license-server settings; never paste license secrets into this lesson.
  • Browser cannot open the page: confirm network access to the published HTTPS endpoint and try again in a clean browser tab.
  • Recording shows no useful requests: confirm that you used the published HTTPS URL, not a local file path, and start recording before opening the HRMS login URL.
  • Replay fails: use one user, inspect the first failed request, and confirm the published application is reachable before increasing load.

Day 1 deliverable

Submit the NeoLoad 2026.02 version evidence, the saved UP_HRMS_Login project or export, the successful one-user replay result, and a short note defining response time, throughput, concurrent users, and error rate.
