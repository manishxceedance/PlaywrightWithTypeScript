Lesson 8: Conditions and Loops in TypeScript

Level: Beginner-Friendly Learn how to make decisions and repeat actions using conditions and loop statements.

Conditions and loops are core programming skills. You use conditions to choose what should happen, and loops to repeat work without copying code.

1. Why Conditions and Loops Matter

In real projects, you constantly ask questions like "Is user logged in?", "Did API return success?", and "Process all rows from this file". Conditions solve the question part, and loops solve the repetition part.

2. if, else if, else

Use if blocks when your code needs to branch based on a boolean condition.

type Candidate = {
  name: string;
  score: number;
};

function getGrade(candidate: Candidate): string {
  if (candidate.score >= 90) {
    return "A";
  } else if (candidate.score >= 75) {
    return "B";
  } else if (candidate.score >= 60) {
    return "C";
  }
  return "Needs Improvement";
}

console.log(getGrade({ name: "Asha", score: 84 })); // B
Explanation:
  1. if checks the first condition. If true, that block runs and function returns.
  2. else if checks additional conditions only when previous ones were false.
  3. else (or final return) handles all remaining cases.
  4. Conditions run top to bottom, so place strictest/highest rules first.

3. switch for Fixed Options

Use switch when one value can match one of many known cases.

function getBrowserMessage(browser: "chromium" | "firefox" | "webkit"): string {
  switch (browser) {
    case "chromium":
      return "Fast and common in CI pipelines";
    case "firefox":
      return "Useful for cross-browser validation";
    case "webkit":
      return "Important for Safari-like behavior";
    default:
      return "Unknown browser";
  }
}
Explanation: switch is easier to read than many if/else checks when comparing the same variable. Each case is a branch. default is the fallback.

4. Ternary Operator

The ternary operator is a short form of if/else for simple expressions.

const retries = 2;
const status = retries > 0 ? "Retrying" : "No retries left";
console.log(status);
Explanation: Use ternary for short assignments. If logic is long or nested, prefer normal if/else for readability.

5. for Loop (Count-Based Repetition)

Use for when you know how many times to run a block.

for (let attempt = 1; attempt <= 3; attempt++) {
  console.log(`Attempt ${attempt}: running health check`);
}
Explanation:
  1. Initialize counter: let attempt = 1
  2. Condition check before each loop: attempt <= 3
  3. Update step after each loop: attempt++

6. while and do...while

Use while when repetition depends on a condition and count is not fixed.

let queueSize = 3;
while (queueSize > 0) {
  console.log(`Processing job. Remaining: ${queueSize}`);
  queueSize--;
}

let attempts = 0;
do {
  attempts++;
  console.log(`Login try: ${attempts}`);
} while (attempts < 2);
Explanation: while checks first, then runs. do...while runs once first, then checks. So do...while always executes at least one time.

7. for...of and for...in

Use for...of for array values. Use for...in for object keys.

const endpoints = ["/health", "/users", "/reports"];
for (const endpoint of endpoints) {
  console.log(`Testing ${endpoint}`);
}

type EnvConfig = { baseUrl: string; timeoutMs: number };
const config: EnvConfig = { baseUrl: "https://api.local", timeoutMs: 5000 };

for (const key in config) {
  const typedKey = key as keyof EnvConfig;
  console.log(`${typedKey}: ${config[typedKey]}`);
}
Explanation:
  1. for...of gives each value directly from iterable items like arrays.
  2. for...in gives property names (keys), not values.
  3. In TypeScript, use keyof when reading object values by dynamic keys to keep type safety.

8. break and continue

Use break to stop a loop completely. Use continue to skip the current round.

const executionTimes = [120, 95, 540, 80, 300];

for (const ms of executionTimes) {
  if (ms < 100) {
    continue; // skip very small values
  }

  if (ms > 500) {
    console.log("High latency found, stopping further checks");
    break;
  }

  console.log(`Normal range: ${ms} ms`);
}
Explanation: This pattern is common in testing and data processing where you may skip noise or stop early when a critical condition appears.

9. Combined Real Example

This example combines conditions and loops to process test results.

type TestResult = {
  id: string;
  passed: boolean;
  durationMs: number;
};

const results: TestResult[] = [
  { id: "TC-01", passed: true, durationMs: 180 },
  { id: "TC-02", passed: false, durationMs: 240 },
  { id: "TC-03", passed: true, durationMs: 620 }
];

let passCount = 0;
let failCount = 0;

for (const result of results) {
  if (result.passed) {
    passCount++;
  } else {
    failCount++;
  }

  const speedLabel = result.durationMs > 500 ? "Slow" : "Normal";
  console.log(`${result.id} => ${speedLabel}`);
}

console.log(`Passed: ${passCount}, Failed: ${failCount}`);
Explanation: Loop through each test result, use conditionals to update counters, and use ternary for compact speed tagging. This is a practical pattern for automation reporting.
